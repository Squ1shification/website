Sliver C2 Evasion Suite
github.com/Squ1shification/Sliver-Evasion-Suite
GoLang · 97★

Four evasion kits for the Sliver C2 framework, each aimed at a different place a beacon normally gets caught:

  • Crystal Palace loader: a position-independent loader built with the Crystal Palace linker.
  • Sleep masking: encrypts the beacon in memory while it sleeps, so a scan during the idle window finds nothing.
  • In-memory PE execution: runs PE payloads reflectively in memory, never touching disk.
  • Remote process injection with PPID spoofing: injects into a remote process and spoofs its parent, so the new thread looks like it came from something benign.
