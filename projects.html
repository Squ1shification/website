Sliver C2 Evasion Suite

Go · 97★

A four-kit defense-evasion suite for the Sliver C2 framework. Each kit targets a different part of the detection surface an operator runs into:

  • Crystal Palace loader — a position-independent loader built with the Crystal Palace linker, so the beacon starts from shellcode rather than a flagged executable on disk.
  • Sleep masking — encrypts the implant’s memory while it sleeps, so in-memory scanners have nothing readable to match between check-ins.
  • In-memory PE execution — runs PE payloads reflectively, entirely in memory, without dropping them to disk.
  • Remote process injection with PPID spoofing — injects into a remote process while spoofing the parent-process ID so the new thread’s lineage looks legitimate.
PNGboomer

Go

A weaponised proof of concept for CVE-2026-77622. It brute-forces the small nonce space on a Sliver HTTP(S) listener and sends a tiny crafted PNG whose declared dimensions blow up to gigabytes on decode, exhausting memory on the C2 server. Published as GHSA-663m-7x7m-g4fw.
