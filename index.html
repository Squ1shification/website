Security advisories
WinFsp — kernel out-of-bounds read & pool memory disclosure. Credited in WinFsp v2.2B4.

A missing per-record bounds check in FspVolumeNotifyWork lets any local user send a FSP_FSCTL_NOTIFY_INFO record whose 16-bit Size claims 0xFFFF bytes. The driver walks ~64 KB of adjacent non-paged pool as a wide-character path — a deterministic kernel bugcheck, and, through directory change-notifications, a kernel memory leak that defeats KASLR. Full write-up & PoC.

OpenSMTPD (OpenBSD) — raw-modifier bypass to code execution. Fixed in OpenBSD 7.9, errata 015. CVE pending.

When OpenSMTPD expands address variables with the raw modifier, the user- and domain-derived parts reached the mail-delivery agent’s environment unfiltered — crafted addresses could smuggle shell-significant characters and reach command execution. Fixed by a new mda_escape() in mda_unpriv.c. Full write-up.

Sliver C2 — unauthenticated PNG-decoder memory-exhaustion DoS. CVE-2026-77622.

Sliver’s HTTP(S) listener decodes attacker-supplied PNGs with no size limit, and its image channel uses only 65,537 nonces. An unauthenticated attacker brute-forces the nonce and sends a tiny “PNG boomer” (e.g. 32767×32767) that decompresses to gigabytes, crashing the C2 server. Full write-up.

Bug bounties & write-ups
Nextcloud — SubAdmin → DelegatedAdmin privilege escalation. Resolved.

Nextcloud’s access-control check blocked SubAdmins from managing full admins but forgot the DelegatedAdmin role. A SubAdmin sharing a group with a DelegatedAdmin could reset that account’s password through the Provisioning API and inherit instance-wide user management. Full write-up.

Google OSS VRP — Carbon-lang pre-commit artifact poisoning. Accepted.

A fork’s pre-commit hooks produced a git diff artifact that a privileged workflow_run job fed to reviewdog with a bot PAT and no fork check — letting a malicious PR post arbitrary review comments as the trusted bot, and retarget any PR by rewriting the event file. Full write-up.
