Research

Bugs I have found and reported. They all got fixed and credited, and each one links to the full write-up.

WinFsp: kernel out-of-bounds read
Credited in WinFsp v2.2B4.

WinFsp’s kernel driver reads a 16-bit size off every notify record and only checks that it is big enough, never that it fits the buffer you sent. Send a record claiming 0xFFFF bytes in a ten-byte buffer and the driver walks about 64 KB past its own allocation, reading kernel pool as if it were a filename. That bugchecks the machine, and with a bit of pool grooming the leaked bytes come back to user space through change-notifications, which is enough to break KASLR. Any local user can do it, and one bounds check fixes it. Full write-up and PoC.

OpenSMTPD: raw-modifier bypass to RCE
Zero-day. Fixed in OpenBSD 7.9, errata 015. CVE pending.

OpenSMTPD builds delivery commands from pieces of the envelope, and the raw modifier is supposed to strip the dangerous characters first. It didn’t. The user and domain parts reached the delivery agent’s environment untouched, so the right characters in an address survive into the shell the MDA runs. I reported it to Gilles, who fixed it with a new mda_escape() across every address field. It shipped as an OpenBSD errata. I wrote it up here, with a short demo.

Sliver C2: unauthenticated PNG DoS
My own CVE: CVE-2026-77622.

Sliver’s HTTP(S) listener decodes any PNG you send it with no cap on the decoded size, and the channel in front of it has only 65,537 nonces to guess. So you brute-force your way in with no auth and send a few-kilobyte PNG that claims to be 32767×32767. Decoding it tries to allocate gigabytes, and the C2 server falls over. Full write-up.

Nextcloud: SubAdmin to global user manager
Resolved.

Nextcloud’s check for whether a SubAdmin can manage a user blocks full admins but forgets the newer DelegatedAdmin role. Share one group with a DelegatedAdmin and you can reset their password over the Provisioning API and log in as them, and they manage every account on the instance. One missing line. Full write-up.

Google OSS VRP: CI artifact poisoning
Accepted.

Carbon-lang runs a fork’s pre-commit hooks and uploads the resulting git diff, plus a copy of the GitHub event, as an artifact. A privileged workflow then feeds that diff to reviewdog with a bot token and never checks it came from the real repo. A fork controls its own diff, so a malicious PR can make the bot post whatever it wants, and by rewriting the event file first you can aim it at any PR. Full write-up.
